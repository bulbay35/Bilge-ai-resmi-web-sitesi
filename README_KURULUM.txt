BILGE AI RESMI WEB SITESI
=========================
1) index.html dosyasini acarak siteyi onizleyin.
2) Yardim/destek Google Forms linki eklendi:
   https://docs.google.com/forms/d/e/1FAIpQLSfnT-JOgRveFjpcm_1-Kn7Qm_10ZZ1mp2Q2Qn2Ot2I9Aql5wQ/viewform
3) GitHub Pages icin bu klasorun ICINDEKI dosyalari repo kokune yukleyin:
   index.html, style.css, script.js, downloads/BilgeAI.zip
4) GitHub -> Settings -> Pages -> Deploy from a branch -> main / (root).
5) Windows Indir dugmesi downloads/BilgeAI.zip dosyasini indirir.
6) Web Deneyin dugmesi https://bilge-ai-ocuc.onrender.com/ adresini acar.

ONEMLI: BilgeAI.zip yaklasik 85 MB. GitHub normal dosya yukleme siniri
100 MB/dosya; GitHub web arayuzu yuklemesinde daha dusuk limitler
olabilir. Git ile push edin veya Release kullanin.
UYARI: Paylasilan Windows EXE icindeki API anahtari tersine muhendislikle
cikarilabilir. Herkese acik dagitimdan once anahtari sunucuya tasiyin.

GitHub web sitesinden 25 MB uzerindeki dosyalari yuklemek sorun olabilir;
Git komut satiriyla push veya Windows EXE icin GitHub Releases kullanin.
GitHub Pages icin repo public olmali veya planin private Pages destegi olmali.
